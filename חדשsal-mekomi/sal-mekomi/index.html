עדכון אוטומטי בחיבור לרשת

הפעילו את start.bat מתוך החבילה, ובחרו רשת. הרכיב המקומי מוריד את קובצי המקור ומעביר אותם לתוכנה.

HTML לבדו עשוי להיחסם בהורדה מאתרי הרשתות. הרכיב המקומי דורש Python 3.10 ומעלה, ללא התקנת ספריות נוספות. אם מקור נחסם או השתנה, השתמשו בהורדה ידנית. שוק העיר מופיע ברשימת הרשתות. לרשת חדשה אפשר לייבא קבצים ידנית ולבחור שם קבוע. קרפור זמין גם בעדכון האוטומטי.
העדכון האוטומטי זמין דרך הרכיב המקומי.

מאיפה מורידים?

הקישורים נשמרים בתוך התוכנה גם אופליין. פתיחת אתר והורדת קבצים דורשות אינטרנט — אפשר להוריד במחשב מחובר ולהעביר ב־USB.

מדריך קצר

  1. פותחים את מקור הרשת ומורידים קובץ Stores עדכני.
  2. מייבאים אותו ובוחרים את הסניף לפי עיר, שם וכתובת; ביש חסד בודקים גם את שם הפורמט בתוך נתוני שופרסל.
  3. מורידים PriceFull של אותו מספר סניף ומייבאים כ־XML, GZ או ZIP. אין צורך לפתוח GZ ידנית בדפדפן עדכני.
  4. מייבאים PromoFull של אותו סניף למבצעים. אפשר לייבא גם לפני המחירון.
  5. ביבוא הראשון לכל מזהה רשת בוחרים את שמה; כך מוסיפים גם קרפור או כל רשת עם קובץ תואם.
  6. במסך הסל כותבים למשל 2 חלב ובוחרים את המוצר המדויק. בתחתית הרשימה מוצג המחיר בכל רשת.
  7. מעדכנים מחירון מלא לפי הצורך או מייבאים קובצי Price חדשים באותו סדר זמן. חוסרים אינם נספרים כאפס.
  8. שומרים גיבוי JSON להעברה למחשב אחר.
מה בדיוק משווים?

מוצר עם ItemType=1 וברקוד GTIN תקין (כולל ספרת ביקורת) מושווה בין רשתות. ברקוד מקומי המתחיל ב־2 אינו מתמזג בין רשתות. מוצר פנימי, או קובץ ללא ItemType, משויך לרשת בלבד. ההתאמה אינה מסיקה שמוצרים דומים הם זהים. מבצעי מחיר ליחידה, חבילות כמות והנחות אחוז מחושבים כשהמחיר והתנאים בקובץ ובתיאור תואמים. תנאים מורכבים מוצגים לבדיקה ואפשר לאשר שיטת חישוב ידנית. פיקדון שאינו במחיר המקור לא מתווסף אוטומטית. קובץ מחירים אינו אישור מלאי או סטטוס פעילות. במוצר שקיל יש לבדוק את יחידת התמחור: אין הנחה שמחיר הפריט הוא תמיד לק״ג. מוצגים מועד הקובץ ומועד עדכון הפריט בנפרד.

קובץ מלא חדש מחליף את מחירון הסניף. קובץ ישן יותר נדחה; קובצי עדכון לא מחליפים בסיס מלא. פריט עם מחיר לא חיובי אינו נכלל. שדה ItemStatus נשמר אך אינו מפורש באופן אחיד בין הרשתות: בקובץ שפע שנבדק כל הפריטים מסומנים 0, ובשופרסל השדה ריק. כל מחיר מוצג כפרסום בקובץ, ללא אישור מלאי או פעילות. מחיר ליחידת מידה מוצג כפי שפורסם, עם תיאור היחידה בלבד — ללא המרה אוטומטית.
